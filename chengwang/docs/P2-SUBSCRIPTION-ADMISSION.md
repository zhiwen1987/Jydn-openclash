## 核心不变量

- SourceID 是独立的随机持久标识，不由来源名称、URL、列表位置或秘密生成。多个来源分别保留 provenance、接纳版本和失败状态，不能因一个来源失败清空其他来源。
- 节点 ID 使用私有键、范围、SourceID 和规范化连接配置的 HMAC，不包含显示名。改名/重排保持 ID；凭据或实际连接语义变化属于不同连接身份，不能跨来源/范围/凭据误合并。导入名称可能夹带秘密，默认不进入公开节点投影。
- 候选摘要为 `hmac-sha256:`，不是原文 SHA256；原始内容及完整节点配置只进入私有存储。错误仅保留闭集代码，不保留解析片段、URL、响应体或上游异常。
- 预算先冻结：每输入 1MiB、每候选 1024 节点、32 来源、64 候选、快照 16MiB、标量 4096 字节、树深 16、语法节点 32768、本地审计最多 4096 条。集合达到任一预算时明确拒绝，不能默默截断后声称成功。此预算是当前实现边界，不是大型企业容量验收。
- 新输入默认隔离。失败、空结果、超限或审核拒绝不改变已接纳指针，不续有效时间，不显示为健康；接纳指针仅指本地库存，不是运行时已验证版本。
- Source revision 初始为 1，新候选导入成功后推进；候选 `baseRevision` 记录导入后的 revision。接纳/拒绝要求当前 revision 一致；旧候选不能覆盖新状态。单独的本地回退仅能引用该源曾接纳的候选，并产生新的单调 revision，而非把版本号倒退。
- 持久化与本地审计同快照结算。本地 hash 链检查一致性，不是外部见证、WORM 或防恶意宿主重写的保证。rename 后目录同步不确定时 poison 并返回 `commit_uncertain`，不能假报成功或自动重试；外部企业审计和跨库协调仍须在产品接线阶段另行完成。
- 抓取策略是受信配置，不是任意客户端 URL。仅明确批准的 HTTPS 来源；URL/query 可能含秘密，公开 DTO 不导出。完整 CNAME/A/AAAA 集合中任一危险地址都拒绝，校验后固定 dial，TLS 保留原主机名。没有继承环境代理、Cookie、重定向或远端配置二次读取。
- 抓取固定连接 3 秒、TLS 5 秒、响应头 5 秒、总计 15 秒；无隐式重试或解压，原文读取超过 1MiB 拒绝。总 deadline 依赖受信 resolver 遵守 context，不能强制中止任意阻塞的自定义实现。HTTP 200 只是抓取成功，不代表解析、准入、节点健康或业务可用。
- 当前解析器只接受明确支持的提供者字段与协议子集；完整 Clash 配置、未实现选项或协议整批拒绝。跨格式默认值等价去重、真实密钥/内核可用性未验收。YAML AST 复杂度校验发生在有界输入解码后，尚不是独立进程 CPU/内存沙箱。
- 幂等键绑定范围、actor、动作和参数，已提交动作不重复执行；重放返回当前安全视图，不承诺原始历史响应逐字相同。相同内容在当前 CAS 下的无变更读取不额外占用幂等记录；本地审计只覆盖成功变更，产品入口的失败尝试与外部审计尚待接线。

## 下一阶段接线约束（尚未实现）

P2-05 应先冻结独立权限和 API 合同，再分别实现产品适配器、审计协调与主服务接线，最后由单一集成者验收：

1. 独立区分读取、导入/来源管理、批准、抓取和本地回退权限；不复用任意草稿权限，也不把核心 actor 字符串当作已认证身份。
2. 严格 Bearer、正常 TLS、范围授权和默认关闭写门先于请求触发的私有内容读取、解析或 DNS/连接；测试需断言拒绝路径的 reader/fetcher 调用次数为 0。启动时受信本地存储初始化不冒充请求级授权。
3. 来源 URL/凭据只由受信配置或秘密引用提供，不接受普通请求临时 URL；批准记录必须绑定来源、范围、策略 revision 和确切允许的来源，变更后不能沿用旧批准。
4. 请求体闭集、大小预算、CAS 与幂等协同；对已提交重放与当前视图区分，`commit_uncertain` 必须显式提示状态可能变化，禁止默认自动重试。
5. 成功本地变更审计之外，还需拒绝/失败尝试和外部耐久审计协调；恢复时对 pending/uncertain 动作实际读回，不伪造已提交结果。匿名能力清单不得读取私有订阅库。
6. 产品 API 的 1/N 来源、坏更新保持原接纳版本、重启读回和范围拒绝闭环通过后，才能进入 P2-06 真实界面及两条浏览器路径；再后面才是完整内核验证、调度、容量及长期观察。
7. 来源/候选列表仅给安全元数据与计数，节点详情采用有界读取/分页，游标绑定范围、来源与 revision；不能把全库 64×1024 节点一次序列化。界面必须标明“本地接纳/本地回退”，不把库存状态称作“已上线/已健康”。
