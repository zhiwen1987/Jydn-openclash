# 澄网产品规格（多内核版）

## 产品定位

澄网不是 OpenClash 的换皮，也不是只能生成 Clash YAML 的订阅转换器。它是一套独立的网络代理与策略路由控制平台：用统一的期望状态描述业务，用可插拔适配器驱动不同数据面内核，并保留每个内核的专有能力。

## 功能地图

### 配置与运行

- 多配置方案、草稿、差异、验证、版本、灰度、回滚
- 规则、全局、直连等运行模式
- 多运行实例和主/备内核切换
- TUN、TProxy、Redirect、Mixed、SOCKS、HTTP 等入站
- 连接列表、实时速率、历史流量、规则命中、连接终止

### 多内核

- 首批适配器：Mihomo、sing-box、Xray
- 扩展适配器：Hysteria、Brook、naiveproxy、WireGuard 及外部 SOCKS/HTTP 上游
- 能力协商：原生支持、适配支持、不支持
- 内核二进制校验、版本通道、沙箱验证、并行实例、无损能力检查
- 内核特有配置保留区，避免统一模型造成能力丢失

### 节点与订阅

- 单个节点、多个订阅、代理提供者、规则提供者
- 自动识别订阅数量与格式、去重、节点改名跟踪、来源追踪
- Shadowsocks、VMess、VLESS、Trojan、Hysteria2、TUIC、AnyTLS、WireGuard、SOCKS、HTTP 等协议模型
- TCP、WebSocket、gRPC、HTTP/2、QUIC、Reality、TLS 等传输与安全层
- 延迟、连通、TLS、HTTP、业务能力、出口位置、IP 稳定度分层评估
- 国家池、业务专用池、手动组、自动组、故障转移组、链式代理

### 精确分流

严格采用以下优先级：

1. 安全与强制规则
2. 自定义业务
3. 国内精确规则
4. 国外业务规则
5. 区域与网络规则
6. 最终兜底

匹配维度包括：精确域名、域名后缀、关键字、GeoSite、IP CIDR、GeoIP、ASN、来源设备/IP/MAC、目标端口、TCP/UDP、进程/应用包名。条件支持 AND、OR、NOT 和分组。

自定义业务高于国内/国外地理兜底。例如 `chatgpt.com` 即使解析结果异常命中国内 IP，也先按“对话助手”业务策略处理；`.cn`、中国 ASN 和国内 IP 在未命中高优先级业务时进入 DIRECT。

每次决策必须产生可解释证据：命中层级、规则、条件、动作、最终节点、回退原因。发布前提供流量模拟、冲突检测、阴影规则检测和不可达规则检测。

### DNS

- UDP/TCP DNS、DoH、DoT、DoQ
- Fake-IP、Redir-Host、真实 IP 模式
- 国内外分流、域名策略、fallback、缓存、预取、hosts、ECS
- DNS 劫持、IPv6 策略、泄漏检测、独立上游健康检查
- DNS 结果和流量路由一致性验证

### 稳定与自动化

- 单一写入者租约、原子状态、幂等协调
- 动作预算、冷却时间、熔断、人工锁定
- 订阅隔离准入、配置沙箱、灰度发布、观察窗口
- 独立 watchdog、自动备份、最后稳定版本回滚
- 完整审计事件：谁、何时、为什么、改了什么、如何恢复

## 准确性边界

分流准确依赖域名可见性、DNS 一致性、IP/ASN 数据新鲜度和应用是否使用加密 ClientHello/自带 DNS。平台必须显示证据可信度，不能把无法观察的流量标为“精准命中”。

## 实施顺序

1. 平台无关领域模型、规则引擎、版本库、审计模型
2. Mihomo 适配器完整能力覆盖和等价性测试
3. sing-box、Xray 适配器与跨内核迁移报告
4. DNS、订阅、节点评估和连接观测
5. 透明代理、防火墙与系统服务适配
6. 自动化、看门狗、备份恢复与高可用
7. 影子运行、灰度接管、故障注入和生产验收
