## 真实浏览器退出条件

每一条路径都必须单独满足：

1. 正常 TLS 实际证书链与真实 API 请求，页面身份正确、非空、无框架错误覆盖层。
2. 真实最新 3 个 runID、15 个分层结论与 6 个原始 API 样本绑定；403/429 不显示为正常业务。
3. 实际清空令牌、卸载明细、匿名摘要，以及桌面 1440 和移动端 375 像素布局与截图。
4. 不改时钟或延长 TTL；自然撤回旧结论，最终读回 0 样本、3 个 unknown。
5. 8 项错误计数全部为 0，包括任何已观测的请求取消；不能自动豁免界面主动取消。
6. 实际 Node/Chrome 正常退出 0、无强制清理或 guard 干预、无所拥有的存活进程。
7. 下载原 ZIP 后安全核对隐藏 manifest、源文件 Git 原字节、完整后端 22 输入，再用精确候选源码的原检查器独立重放；不得手补缺失文件。

## 剩余边界

浏览器仅访问隔离 namespace 的 loopback API；探针目标由该实验内的 `8.8.4.4` fixture 提供，没有公网出口。即使本阶段通过，也仍需后续真实订阅准入、完整内核配置及数据面验证、隔离发布/回滚、长期故障观察，以及另行授权的生产备份、灰度和读回。完整项目进度见[项目台账](PROJECT-PROGRESS-LEDGER.md)。

CI 工件保留期为 14 天，独立复核的本机 Temp 目录也不是永久备份；本文保存入口和摘要，不冒充已完成永久集中归档。长期证据保留策略及系统级恢复演练仍属于未完成项。
