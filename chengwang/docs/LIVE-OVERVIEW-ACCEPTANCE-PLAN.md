# 实际证据总览：实施与验收清单

状态：开发候选，尚未编译、运行新Go／前端测试或取得新总览的真实浏览器证据。此页不是上线报告。

## 用户能得到什么

运行总览保留“示例”与“实际证据”两个明确入口。默认仍展示示例；选择实际证据后，通过新的只读API读取当前控制面缓存摘要。实际证据没有覆盖的业务、节点池、端到端DNS、设备库存和流量拓扑直接标明未覆盖，不用演示数字补齐。

订阅仅显示“是否配置”；来源数、节点数保持null／未知，没有枚举受保护私有库存。控制器、探针、存储和时钟字段描述各自缓存状态，不能由其中一个available推导业务网站或全网健康。

读取中、超时、失败、离开页面和迟到结果都须清除或隔离旧“实际”标识。实际总览不会替换配置编辑器使用的示例Snapshot，也不授予发布或写入权限。

## 接线

- 开关：`CHENGWANG_LIVE_OVERVIEW_ENABLED`，缺省、空值和false关闭，true开启，其他值固定错误；拒绝时不部分修改配置。
- API：`GET /api/v1/overview`。关闭或provider不可用时返回固定503；不读私有Details、不刷新、不访问上游。拒绝其他方法、查询串、请求正文和编码。
- DTO：`chengwang.overview-snapshot/v1`；字段全部必需，未知时间和数量显式null。配置模式取真实配置，不固定成Shadow，不由模式推导生产已授权。
- 预算：合作式500ms组装预算、64KiB响应，客户端5秒截止。同步缓存Status锁不能被context强行中断，此限制保留，不承诺硬实时。
- 写门、现有编辑器Snapshot、现有worker和上游行为保持；成功读取不能当作完整设备或业务测量。

精确字段、时间和状态组合约束见[冻结合同](LIVE-OVERVIEW-CONTRACT-v1.md)。
