- `MetaCubeX/meta-rules-dat`, generated `meta` revision
  `9f2b7462c7508ad85a1137e70d502b783c89794d`. GitHub identifies the project as
  GPL-3.0; its license is retained as `MetaCubeX-meta-rules-dat-LICENSE`.
- `Aethersailor/Custom_OpenClash_Rules`, revision
  `ce364895f9b55317159b43c0397788933f0f8448`. Its README declares the author's
  original content CC BY-SA 4.0 while third-party material keeps its own terms.
  The legal code is retained as `CC-BY-SA-4.0-LICENSE.txt`.

The pack preserves source URL, revision, raw content and SHA-256 for offline
reproduction. This repository adds the matcher, policy labels and reports; it
does not claim that every sampled domain is currently reachable or blocked.
Nested third-party data may carry additional terms; redistribution of the raw
pack therefore remains a review risk even with these notices.
