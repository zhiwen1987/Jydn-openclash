# Clash Stack 0.1.0 候选安装包与轻量化验收

日期：2026-10-26。这里验收的是应用层安装包，不是固件刷写工具，也不是互联网可用率认证。生产旁路由没有切换到本安装包。

**当前状态：候选版，最终整体验收待完成。** 早期代码已跑通以下完整安装、升级和回退。最后回归时，其他业务容器在验收窗口重启，同时发现检测组轮换被恢复保护误判；现已修复检测组判断、事务关联和历史比较范围，完成针对性恢复与故障检查。用户确认 249 仍有并行任务运行，因此没有将最新修复版本标为全环境验收通过。

## 实测环境

- Docker 主机 10.88.0.249 上新建独立测试容器，使用 23101/23102/23103 和 DNS 2053，未占用生产 3101/3102/3103/53。
- 旁路由为独立 QEMU/OpenWrt 24.10.4 副本，MAC `02:00:00:26:10:26`；生产 254 的 MAC `00:0c:29:2d:96:e8` 仅用于只读身份核验。
- OpenClash 0.48.002，固定 Mihomo SHA-256：`59198acb9b851f59ab328396684bc8c1ec70c432f8f1cd035c27ad2fdf549b08`。
- 操作端实测 Windows 内置 Python 3.13.17、系统 PowerShell 启动器；Linux 3.12 随包依赖和命令入口另行验证。Linux 3.11/3.13 仅完成依赖散列与共享打包检查，没有分别跑完整远程安装。
- 两路测试订阅使用现有节点缓存的受限临时副本，一路 YAML、一路 Base64 YAML；没有切换生产节点或重新获取生产订阅。凭据不进入本包或公开报告。

## 已测性能优化

| 项目 | 优化前 | 优化后 | 条件 |
|---|---:|---:|---|
| 随包依赖目录 | 79,041,426 B | 36,845,326 B | 共用相同 ABI3 / 纯 Python 依赖，减少约 53.4%；不是整包减半 |
| 内核原生校验时间 | 72.416 秒 | 13.099 秒 | 相同核心、规则数据库；对比 standard / memconservative |
| 同项峰值 RSS | 366,928 KiB | 163,796 KiB | 约 358 / 160 MiB |

内核对比在独立容器内限制 0.75 CPU、512 MiB、无网络，关闭监听和 DNS，并以本地 provider 夹具避免下载；只用于比较数据加载器，不代表完整配置冷启动、网页访问或业务账户速度。

另外减少了空节点时的整图轮询，使用发布标记唤醒发现；恢复选择共用一次策略图；镜像 ID 已匹配时跳过重复加载；构建去掉一次重复整包散列读取。保留散列、身份和回退检查。

三节点实验站点一次稳态采样：容器约 177.3 MiB，Docker CPU 约 1.38%（单核口径）。这是瞬时样本，不是压力测试或资源占用上限，不能与业务量不同的生产容器直接比较。

## 必须保留的边界

1. 锁定入口约束实际命中该策略组的流量。现有模板中 `gstatic.com` 由更靠前的 `Custom_Proxy_Domain` 分到手动选择，不能宣称选择 Google 组便锁定整个 Google 域名族。此次性能与安装优化未擅自调整生产规则优先级；需另行审阅规则后处理。
2. 当前是一个容器和一台旁路由。升级中心会短暂重启 Kuma/DNS 等进程，不能承诺零中断。双端提交不是跨设备原子事务：若在中心确认后操作端退出，旁路由仍有独立回退，中心可能保留新版本；应查看两端事务记录后恢复或完成验收。
3. 0/1/2 个来源均完成配置生成及原生校验；完整远程安装跑通的是两来源环境。零来源仅完成空态服务检查和 DNS 发布拒绝检查，没有把它称为代理业务可用。
4. Grok 宿主机上的外置专用故障切换任务不在此包的自动搬迁范围；接管不会删除原任务，新部署也不会自动获得它。
5. 真实 App 登录、支付、流媒体账号、蜂窝外网入口、所有业务地区可用性和全体节点协议没有在本次逐一验收。Google/百度的网络请求结果不代表全部业务成功。
6. 本轮安装成功后的整机重启没有另做全流程演练；冷启动安装及异常重启后的回退已实测。跨架构、其他 OpenClash 版本、Kuma 跨版本数据库升级均不在支持范围。
7. 包内只含程序、固定依赖和规则快照；不含真实订阅、节点密码、SSH 私钥和生产数据库。第三方数据及程序仍受各自许可约束，不将此包当成可任意公开转售的授权证明。
