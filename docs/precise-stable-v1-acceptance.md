# 精准稳定版 v1 生产验收方案

## 发布原则

- 当前运行的 `转换.yaml` 永不原地覆盖。
- 候选配置使用独立文件 `精准稳定-v1.yaml`。
- GitHub 先发布候选分支，验证通过后才允许合并主分支。
- 修改旁路由前必须创建并验证新的完整备份。
- 切换前在旁路由本机启动失联自动回滚；SSH 或互联网中断不影响回滚。

## 四道验收门

### 1. 仓库静态验收

- `scripts/build.py` 可重复生成且工作区无意外差异。
- `scripts/validate.py` 通过。
- Python 文件通过语法编译。
- Ruby 运行期补丁测试通过。
- 无重复策略组、循环引用、缺失目标或业务组自引用。
- 每个功能父组和具体业务组的第一项保留原默认策略，后续项按统一顺序提供 `DIRECT`、隐私代理、稳定自动、自动选择、手动选择、八个国家组、流媒体节点和 `REJECT`。
- 本地网络、联网检测和广告拦截保持预定义的精简安全菜单，不提供可能破坏局域网或联网状态的国家覆盖。
- 业务组不得引用自身、不得有重复选项；订阅中为空的国家/节点池应由运行期补丁自动隐藏。
- 自动池为 15 个，间隔 300 秒、容差 100 ms。
- Netflix 默认进入“流媒体节点”，该池使用 Netflix HTTPS 地址探测；不能仅以 Cloudflare 测速成功代替 Netflix 实际连通。
- 人工智能默认进入新加坡自动池；ChatGPT、Claude、Gemini、Grok、Perplexity 和 Microsoft Copilot 必须各连续通过三次沙箱 HTTPS 测试。

### 2. 双订阅生成验收

- 两个订阅均生成独立 `proxy-provider`。
- 节点数量与当前基线相比没有非预期减少。
- 订阅提示节点不会进入自动池。
- 香港、台湾、日本、新加坡、韩国、美国、英国、德国分类均有样本验证。
- 未预定义地区进入“其他地区”。

### 3. 路由器离线验收

- 候选配置只上传到新路径，不修改 `config_path`。
- 使用路由器当前 Mihomo 内核执行 `-t` 校验。
- 所有规则提供者可下载，GeoSite/GeoIP 分类均存在。
- 运行期分组补丁在候选副本上执行，不改活动配置。
- 补丁执行后再次运行内核 `-t` 校验。

### 4. 受保护灰度切换

- 切换前保存活动配置路径和 OpenClash UCI。
- 启动 10 分钟独立回滚计时器；未收到成功标记就恢复旧配置并重启。
- 切换后验证进程、控制接口、DNS、TCP、UDP、IPv4 和防火墙规则。
- 验证国内直连、国外代理、AI、GitHub、流媒体和智能家居。
- 验证 `.cn`、AMD 中国开发者、涂鸦智能及用户专用域名仍为直连。
- 观察日志无配置、规则、DNS、连接和 provider 错误。
- 用户实际打开常用网站确认后，才取消自动回滚。

## 必测业务

| 类型 | 验收项 |
| --- | --- |
| 国内 | 百度、`.cn`、国内银行、政务、AMD 中国开发者 |
| 智能家居 | 涂鸦云端域名与远程控制 |
| AI | ChatGPT、Claude、Gemini、Grok、Perplexity、Microsoft Copilot |
| 开发 | GitHub、GitHub Copilot、Docker、NPM |
| 通信 | Telegram、Discord、WhatsApp |
| 流媒体 | YouTube、Netflix、Disney+、Spotify |
| 兜底 | 未分类国内 IP、未分类海外域名、非标准端口 |

## 回滚条件

出现以下任一情况立即回滚，不在候选配置上连续试错：

- OpenClash/Mihomo 未在预期时间启动；
- 路由器本机 DNS 查询失败；
- 国内直连或国外代理连续三次失败；
- 管理地址、SSH 或控制接口失联；
- 日志出现缺失策略组、缺失 GeoSite、YAML 解析或 provider 加载错误；
- 用户常用业务发生明显回归。
