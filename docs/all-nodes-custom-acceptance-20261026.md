当前仅保留一个无后缀的 `🔐 自定义节点`。本轮将菜单从只有 REJECT 扩展为当前已加载的全部实际节点，订阅与自建节点统一手动选择。

生产验收结果：

- 唯一入口包含 47 个实际节点及 REJECT；已与全部声明 provider 的运行节点清单和已定义节点核对。
- 默认及上线时的当前选择仍为 REJECT，没有为任何原业务切换出口。
- 原 142 条规则、DNS 配置和原有业务选择保持一致，旧的带业务后缀入口为 0。

- 安装的最后覆写钩子、私有配置和绑定表仍保留；没有修改订阅凭据或共享节点参数。

生成器和配置验证、17 项 Ruby 测试、12 项控制器回归通过。生产同一 Mihomo 内核在 network=none 临时容器执行 41 项 HTTP/DNS 故障测试通过，包括两个 provider 和静态节点同时可选、排除伪装的 Direct 节点和通知条目、订阅节点失败后不切换、删除选中节点后进入 REJECT、源刷新后新节点可选、其他业务继续正常。
